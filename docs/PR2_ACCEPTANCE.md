## 本次修正

- 研究工具三個原有區塊保留 `<details>`，初始全部收合、可同時開啟。A/B 保留獨立入口。補上執行期間的 `hashchange`，讓 `#strategy`、`#flows`、`#report` 舊連結及網址片段切換均會開啟對應區塊。
- 估值報告在 `beforeprint` 展開，`afterprint` 還原三區的開合狀態；報告按鈕與瀏覽器直接列印共用此處理。手機收合標題提供至少 44/48px 操作高度與鍵盤焦點提示，表格可橫向捲動。
- 歷史日誌保留訊號時間、原始進出場價、離場原因、成本後淨報酬，以及原始價格的 MFE/MAE。MFE 為非負值、MAE 為非正值，包含進場 K 線及出場開盤；**不包含出場 K 線後續高低價**。未平倉不虛構平倉。
- 新增策略／多空方向／離場原因分組檢討，以本次全部已平倉交易計算筆數、勝率、平均淨報酬、平均 MFE/MAE。介面逐筆表各策略顯示最近 20 筆；CSV 保留本次全部已平倉交易、標的、週期、行情來源與執行時參數。改成本輸入後尚未重跑，CSV 仍是上次執行快照。
- 僅登入後、A/B 頁在前景、真實來源且已收盤的進場訊號才新增裝置觀察紀錄。切換帳號／股票／D1/H1 分區，依訊號 K 線＋策略＋方向去重，以首次觀察為準，各區保留最近 250 筆。DEMO 來源或 DEMO 代碼皆不記錄。日 K 收盤加 90 秒緩衝，H1 沿用既有已收盤篩選。
- 明確標示「本裝置觀察到的進場訊號」及「歷史回測交易日誌與訊號檢討」。裝置觀察不是實際成交、不是背景連續蒐集，也不是雲端推播歷史；本機儲存受瀏覽器資料清除影響，不提供跨裝置同步。
- 修正 H1 請求／檔案讀取期間切換帳號或標的的競態。帳號切換清除 H1 記憶體快取、自動更新與匯出閉包；行情更新、來源切換、週期或股票切換、無標的時，清除失效回測及 CSV。
- 更新 PWA cache 名稱，讓更新後能換用新資源。策略引擎、推播、個人 API Key 流程與 Worker 原始碼均未修改。

## Android 手機驗收（待實機）

先確認載入的是 **PR 分支的新建置**。現有安裝 APK 和正式 main 網址不會因 PR 更新而自動加入功能。可在 GitHub Actions 的既有 `Build Android APK` 工作流程選 **Run workflow → ui/collapsible-research-tools**，下載成功執行的 APK；或在該分支本機建置。這次未觸發建置、未發佈 APK、未合併或部署正式站。

1. 直式開啟「05 研究工具」，三區均收合。依次點開策略、法人、估值，確認可三區同開、單獨關閉，表單與圖表可操作；確認底部五個入口及「04 A/B」獨立入口可點。再橫置，檢查圖表及表格橫向捲動。
2. 網頁版分別開同一測試站的 `#strategy`、`#flows`、`#report`，確認進研究頁且對應區展開。載入有財報的行情，按「列印 / PDF」，確認預覽有完整估值與財報圖、沒有其他研究區；取消後開合狀態還原。APK 的系統列印支援需另外確認。
3. 到 A/B 使用現有日 K 行情，選 A/B 同時比較，開啟空單，執行回測；展開「歷史回測交易日誌與訊號檢討」，確認多空及離場原因分組。CSV 列數扣標題應等於 A＋B 的已平倉筆數，不限畫面顯示的每策略 20 筆。
4. 匯入已有的 60 分 K JSON 切 H1；測試不需新增付費行情。確認換週期、標的或刷新行情後，舊 CSV 停用，重跑後匯出屬於新標的／週期。既有個人 Fugle 功能仍可使用自己的 Key。
5. 登入甲帳號，以真實行情在 A/B 前景查看；**只有當最後已收盤 K 線確實通過進場條件才新增觀察**，無訊號時 0 筆正常。重整後筆數不重複；切股票、日 K／H1，清單各自獨立。切乙帳號確認不出現甲帳號舊紀錄，再切回甲確認保留。
6. 載入示範行情，確認不產生觀察紀錄；未登入也不顯示私人觀察清單。以各帳號自己的 Key／通知設定驗證既有行情及推播，這部分需要實際帳號、網路與 Android 裝置，尚未代為實測。
