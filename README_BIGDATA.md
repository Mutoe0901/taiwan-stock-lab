# 台股研究室 Taiwan Stock Lab — Big Data 更新版

這個版本延續原 Android 0.1.0 的 Web 核心，新增「大數據多頭機率分析」頁面，並保留原有個股總覽、策略回測、資金流向、財報與估值功能。

## 新增功能

- 7 項目前條件：20 日均線、20/60 日均線排列、MACD、量能、20 日突破、外資＋投信、RSI(14)。
- 歷史相似日搜尋：可調寬鬆 / 標準 / 嚴格門檻。
- 5 / 10 / 20 / 60 個交易日後統計：
  - 有效樣本數
  - 上漲比例
  - 平均報酬
  - 中位數報酬
  - 平均盈虧比
  - 平均期間最大不利變動（MAE）
  - 最差 / 最佳結果
- 最低樣本數警示。
- 統計 CSV 匯出。
- PWA manifest 與 service worker，可作為靜態網站部署後加入主畫面。
- PWA / Web 模式新增瀏覽器直接向 FinMind 查詢的程式路徑；是否可用仍取決於 FinMind 與瀏覽器當下的 CORS / Token / 額度限制。

## 分析定義

「上漲比例」是歷史相似條件在指定交易日數後，收盤價高於訊號日收盤價的比例。它是條件式歷史統計，不是未來價格保證，也不是自動買進訊號。

歷史樣本條件只使用該日及其以前的資料；後續報酬才使用未來 5 / 10 / 20 / 60 日資料，以避免條件端直接偷看未來。

## Android 測試 APK 注意事項

`taiwan-stock-lab-bigdata-test.apk` 是以現有 0.1.0 APK 為基底替換 Web 資源後重新測試簽署的版本。因為先前原始 Android 專案 / 私鑰不在目前可取得的檔案中，所以它不是用原本同一把簽章金鑰產生。

若手機已安裝舊測試 APK，Android 可能因簽章不同而拒絕覆蓋安裝。請先從舊版「匯出 JSON」備份真實行情，再視需要解除安裝舊測試版後安裝新版。若要做到日後可直接覆蓋升級，應使用你固定保存的 release keystore 重新由原 Android 專案建置。

## PWA / Web 使用

`web/` 內是可部署的靜態檔案。放到 HTTPS 靜態網站主機後即可開啟，並可用「加入主畫面」方式安裝成 PWA。

核心檔案：

- `web/index.html`
- `web/main.js`
- `web/style.css`
- `web/mobile.css`
- `web/manifest.webmanifest`
- `web/sw.js`
- `web/icon.svg`

## 2.1 多檔掃描選股
首頁改為「掃描選股」。載入多檔股票後，系統會以相同歷史條件批次計算並排序。可調整觀察期、相似門檻、最少樣本及最低目前多頭條件。排序只用於縮小研究範圍，不能視為未來報酬預測或買進建議。

建議真實資料至少準備 3 年以上日線；歷史樣本太少時，掃描頁會標示較低的樣本可信度。FinMind 直接抓取目前一次最多 10 檔，因此此版本是「自選池掃描」，不是全市場即時掃描器。
